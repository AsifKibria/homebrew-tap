# Asif Kibria’s Homebrew tap

## Abu Sayed Bangla Keyboard

For Apple Silicon and Intel Macs running macOS 13 or later:

```sh
brew install --cask asifkibria/tap/abu-sayed
```

Use the full package name. Homebrew installs the tap and trusts this specific cask automatically; a separate `brew tap` command is not needed. This also avoids the untrusted-tap validation error caused by tapping before granting trust.

After installation, enable **আবু সাঈদ** in **System Settings → Keyboard → Text Input → Edit → + → Bangla**.
